# PokéSurvivor 區網部署說明

遊戲可以架在區域網路內的一台電腦上，不需要網際網路、不需要 Firebase。
帳號、存檔、排行榜都保存在那台電腦的 `server/data/` 資料夾。

## 需求

- Node.js 18 以上（伺服器那台電腦）。不需要安裝任何套件。
- 其他裝置只要有瀏覽器，連到同一個區網即可。

## 打包（在開發機）

```
cd /Users/benji/Desktop/pokesurvivor
node tools/build.js && node tools/export_data.js && python3 tools/make_seo_pages.py
zip -r ~/Desktop/pokesurvivor.zip . -x ".git/*" "tools/cache/*" "server/data/*" "*.DS_Store"
```

第一行只在改過程式之後需要（產生 `index.html`、`js/app.min.js`、`version.json`）。
壓縮檔排除了 git 歷史、建置快取與伺服器上的玩家資料。

## 執行（在伺服器那台電腦）

```
cd pokesurvivor
node server/server.js
```

啟動後會印出區網網址，例如 `http://192.168.1.10:8877/`。其他裝置用瀏覽器開這個網址就能玩。

- 換埠：`PORT=3000 node server/server.js`
- 防火牆要允許該埠的連入。Windows 第一次啟動會詢問是否允許 Node 使用網路，選「私人網路」允許。

### 讓它在背景常駐

最簡單：

```
nohup node server/server.js > server.log 2>&1 &
```

較正式（用 pm2，重開機也能恢復）：

```
npm i -g pm2
pm2 start server/server.js --name pokesurvivor
pm2 save
pm2 startup        # 依照它印出的指令設定開機啟動
```

## 管理帳號

```
node server/server.js --list                       # 列出所有帳號
node server/server.js --reset 名稱 新密碼            # 幫忘記密碼的玩家重設
```

## 資料與備份

`server/data/` 內有：

| 檔案 | 內容 |
|---|---|
| `accounts.json` | 帳號（密碼只存雜湊） |
| `sessions.json` | 登入的 token |
| `saves/<名稱>.json` | 每個帳號的存檔 |
| `ranking.json` | 排行榜 |
| `profiles.json` | 個人檔案 |

備份就是複製整個 `server/data/` 資料夾。

## 更新遊戲版本

1. 在開發機重新建置並打包。
2. 在伺服器上覆蓋所有檔案，**但保留 `server/data/`**。
3. 重新啟動伺服器（pm2 的話：`pm2 restart pokesurvivor`）。

正在玩的玩家會在 5 分鐘內自動重新載入新版本；進行中的對戰不受影響，結束後才更新。

## 區網模式與線上版的差別

- 伺服器啟動時遊戲會自動偵測（`/api/ping`），偵測到才用區網模式；放到其他地方（例如 GitHub Pages）仍會走原本的 Firebase。
- 區網模式下：所有帳號自動互為好友、排行榜是伺服器自己的、合作模式經由伺服器連線，隊友斷線會保留位置一分鐘可重連。
- 忘記密碼沒有 Gmail 綁定，由管理員用 `--reset` 重設。

## 用 Docker 執行

專案已附 `Dockerfile` 與 `docker-compose.yml`，伺服器那台電腦裝好 Docker 後，在專案資料夾執行：

```
docker compose up -d --build     # 建立映像並在背景啟動（第一次或更新版本後都用這個）
docker compose logs -f           # 看即時 log（Ctrl+C 離開，伺服器不會停）
docker compose logs --tail 200   # 看最後 200 行
docker compose ps                # 看是否在跑
docker compose restart           # 重新啟動
docker compose down              # 停止並移除容器（資料保留）
```

- 玩家資料放在 Docker volume `pokesurvivor-data`，容器刪掉或更新映像都不會清掉。
  要備份：`docker run --rm -v pokesurvivor-data:/d -v "$PWD":/out alpine tar czf /out/pokesurvivor-data.tgz -C /d .`
- 換埠：改 `docker-compose.yml` 裡 `ports` 的左邊數字，例如 `"3000:8877"`。
- 管理帳號：
  ```
  docker compose exec pokesurvivor node server/server.js --list
  docker compose exec pokesurvivor node server/server.js --reset 名稱 新密碼
  ```
- 更新版本：把新壓縮檔解壓覆蓋後，再跑一次 `docker compose up -d --build`。
- 容器設定 `restart: unless-stopped`，主機重開機後會自動再啟動。
